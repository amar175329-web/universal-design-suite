# Scroll World

Scroll-scrubbed 'fly through the world' landing page — one continuous pre-rendered camera flight with no cuts, scenes generated with Higgsfield.

- **Author:** oso95 ([`oso95/scroll-world`](https://github.com/oso95/scroll-world))
- **License:** MIT (included in [`LICENSE`](LICENSE))
- **Status:** ✅ Vendored from [`oso95/scroll-world`](https://github.com/oso95/scroll-world); original `LICENSE` included

## Files

- `SKILL.md`, `references/` (pipeline, prompts, scrub engine, page template, knockout script)

## Install

```bash
cp -r skills/scroll-world ~/.claude/skills/

# Or from source
npx skills add oso95/scroll-world
```

## Notes

Needs a Higgsfield account and credits for image/video generation, and a video model for the camera clips (the skill re-checks availability each build).
