# Character Prompt Design

Iterative method for AI character / agent persona prompts — clarify scope before drafting, draft into structured fields, revise consistently across fields, ship with safe defaults, capture lessons.

## Files

- `SKILL.md`, `reference.md` (field templates, archetypes, scope-discipline patterns), `templates/character-payload.json`, `lessons.md`

## Install

```bash
cp -r skills/character-prompt-design ~/.claude/skills/
```

## Notes

Built shipping a roster of advisor characters to a Strapi CMS; the method is CMS-agnostic. Includes vocabulary guards in both directions (bro register *and* patronising register) and an em-dash ban.
