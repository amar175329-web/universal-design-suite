# Humanizer

Removes signs of AI-generated writing from text, based on Wikipedia's 'Signs of AI writing' guide.

- **Author:** blader ([`blader/humanizer`](https://github.com/blader/humanizer))
- **License:** MIT (included in [`LICENSE`](LICENSE))
- **Status:** ✅ Vendored from [`blader/humanizer`](https://github.com/blader/humanizer); original `LICENSE` included

## Files

- `SKILL.md`

## Install

```bash
cp -r skills/humanizer ~/.claude/skills/

# Or from source
git clone https://github.com/blader/humanizer.git ~/.claude/skills/humanizer
```

## Notes

Invoke with `/humanizer` and paste the text. Read-only skill (`allowed-tools: Read`).
