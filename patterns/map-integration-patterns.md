# Map & Route Visualization Patterns

## Patterns Extracted from Leaflet, MapLibre GL, and React Map GL
1. **Interactive Route Container**: Full-bleed or card-bounded WebGL map canvas with zoom/pan restrictions and gesture handling.
2. **Route Polyline Elevation Overlay**: Color-coded GPS tracks based on pace, elevation gradient, or heart rate zone.
3. **Location Marker Callouts**: Accessible SVG marker pins with animated pulse radar rings and popover summary cards.
4. **Mobile Responsive Map Controls**: Floating bottom control sheet showing distance, pace, elevation gain, and turn-by-turn waypoint cues.
