# AI & Conversational UI Design Patterns

## Patterns Extracted from assistant-ui, CopilotKit, and Lobe-Chat
1. **Streaming Message Bubbles**: Immediate typing feedback with blinking cursor indicator.
2. **Generative UI / Structured Tool Outputs**: Render custom interactive cards for function calls (e.g. charts, tables, interactive forms) inline in the chat history.
3. **Prompt Textarea & Command Palette**: Expanding textarea supporting file attachments, slash commands, voice input indicators, and token usage meters.
4. **Reasoning Collapsible Accordion**: Monospace reasoning disclosure widget showing thought progression without cluttering output.
5. **Citations & Grounding Chips**: Hoverable chips with source title, favicon, and quotation preview.
