# Responsive Layout Architecture & Breakpoints

## Core Strategy
Mobile-first fluid responsive grid matching modern standards:
- Mobile (<640px): Single-column stack, full-width cards, sheet drawer navigation, sticky bottom actions.
- Tablet (640px - 1024px): 2-column grid, compact sidebar icon rail, collapsible secondary panels.
- Desktop (1024px - 1536px): Multi-column grid, full sticky collapsible sidebar, breadcrumbs, command bar.
- Ultra-wide (>1536px): Max-width bounded content container ( or ), balanced negative space.
