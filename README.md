# Universal Design Suite

**The Unified Autonomous Design Engineering & UX Ecosystem for Antigravity, Claude Code, and Modern Web Projects.**

Version: `1.0.0`
License: MIT (with constituent open-source licenses cataloged and preserved)

---

## Overview

The **Universal Design Suite** consolidates and unifies the capabilities of **64+ foundational design and frontend repositories**, transforming them into a single, permanent, installable, and recoverable ecosystem.

- **292 Unique Canonical Skills** (motion, typography, design systems, visual critique, component engineering, taste aesthetics, and accessibility)
- **12 Integrated Plugins & Antigravity Adapters** (21st.dev, Impeccable, UI/UX Pro Max, ScrollCraft, Taste-Chen, Taste-Leon, Sepia, Tool-UI, Penpot, CopilotKit, Shadcn, Claude Workflow)
- **6 Configured MCP Servers** (MagicUI, 21st Magic, CopilotKit Docs, Assistant-UI, Penpot, Mantine)
- **10 Accessible CLI Tools** (`uipro`, `impeccable`, `skillui`, `playwright-cli`, `shadcn`, `magic`, `create-assistant-ui`, `tool-agent`, `tailwindcss`, `lobe`)
- **24 Design Slash Commands** (`/polish`, `/critique`, `/audit`, `/animate`, `/layout`, `/typeset`, `/normalize`, `/clarify`, `/delight`, `/harden`, `/onboard`, etc.)
- **74 Full Company Design Systems** (Apple, Stripe, Linear, Notion, Raycast, SpaceX, Tesla, Airbnb, Figma, Framer, Vercel, Supabase, IBM, etc.)
- **10 Extracted Component Suites** (Loading states, stats cards, dashboard shells, sidebars, empty states, dark mode, command palettes, charts)
- **6 Core Architectural Pattern Guides** (Responsive layouts, AI interfaces, animation orchestration, map integration, design tokens, health/nutrition dashboard metrics)

## One-Command Installation

To restore and configure all capabilities across any Antigravity or AI coding environment:

```bash
npx universal-design-suite@latest install --all
```

Or clone and install locally:

```bash
git clone https://github.com/amar175329-web/universal-design-suite.git
cd universal-design-suite
node install.mjs --all
```

Or run the shell installer:

```bash
./install.sh --all
```

## Design Slash Commands Reference

| Command | Purpose & Domain |
|---|---|
| `/polish` | Final micro-alignment, spacing rhythm, typography, and detail pass. |
| `/critique` | Deep multi-perspective UX review with heuristic scoring and actionable feedback. |
| `/audit` | Technical quality checks across accessibility (WCAG AAA), performance, and anti-patterns. |
| `/animate` | Purposeful motion design, easing curves, and micro-interactions. |
| `/layout` | Fluid grid composition, spacing balance, and visual hierarchy correction. |
| `/typeset` | Typographic scale, measure, leading, weight, and font pairing refinement. |
| `/normalize` | Design token extraction, color unifying, and spacing scale normalization. |
| `/clarify` | UX copy, microcopy, label, and empty-state copywriting clarity. |
| `/delight` | Playful micro-interactions, sound cues, and visual surprises. |
| `/harden` | Production edge cases, overflow resilience, i18n, and error handling. |
| `/onboard` | New user activation flow, empty states, and contextual tooltips. |
| `/distill` | Decluttering, noise reduction, and minimalist focus. |
| `/colorize` | Strategic palette injection, saturation tuning, and contrast balance. |
| `/bolder` | High-impact visual personality and architectural weight. |
| `/quieter` | Visual de-escalation, calm aesthetics, and restrained tones. |
| `/overdrive` | Shader effects, spring physics, and 60fps canvas reveals. |
| `/shape` | Pre-code design brief and multi-round discovery interviews. |
| `/live` | Interactive browser hot-swap variant experimentation. |
| `/document` | Auto-extracts design system into tool-compatible DESIGN.md format. |
| `/extract` | Consolidates repeated patterns, components, and tokens into reusable systems. |
| `/adapt` | Viewport adaptation, fluid scaling, mobile breakpoints, and touch ergonomics. |
| `/explore` | 21st.dev UI component search and community design exploration. |
| `/sync` | Synchronizes local design tokens with external registries. |
| `/loop` | Gauntlet loop continuous visual verification and browser testing iteration. |
